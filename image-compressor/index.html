    How to compress an image

    1. Drop one or more JPG, PNG or WebP images onto the tool, or tap to choose them.
    2. Pick JPEG or WebP output, adjust the quality slider and optionally set a maximum width.
    3. Check the before/after sizes and percent saved, then download each file or all at once.

    What is an image compressor?

    An image compressor is a tool that makes image files smaller by re-encoding them with lossy compression and, optionally, reducing their pixel dimensions. Lower quality settings discard fine detail the eye rarely notices, which typically cuts JPEG photo size by 40–80%.

    This compressor runs 100% in your browser using the HTML Canvas API: each image is decoded, optionally scaled to your max width, and re-encoded as JPEG or WebP at the quality you choose. Files never leave your device, there is no file-count limit, and the page keeps working offline once loaded. WebP output is usually 25–35% smaller than JPEG at similar visual quality.

    Frequently asked questions

    Is this image compressor free and private?

    Yes. It is completely free and your images never leave your device. Compression happens locally in your browser with the Canvas API, so nothing is uploaded to a server.

    What quality setting should I use?

    A quality of 70–80 is a good default for photos: files usually shrink by more than half with no visible loss. Use 50–60 for the smallest size, or 85–90 when detail matters.

    Should I choose JPEG or WebP?

    WebP is typically 25–35% smaller than JPEG at the same visual quality and supports transparency. Choose JPEG when you need maximum compatibility with older apps and email clients.

    How do I compress an image to under 100 KB?

    Lower the quality slider and set a max width such as 1280 or 1080 pixels. Reducing dimensions has the biggest effect on file size, and the tool shows the new size instantly.

    Can I compress many images at once?

    Yes. Drop as many images as you like; they are compressed in a batch with the same settings, and you can download each file or use Download all.

    Why did a file get bigger?

    Already-optimized images or PNG graphics can grow when re-encoded. If the result is larger than the original, the tool keeps your original file so you never download a bigger image.
